# パッケージ混入

Git に載るパッケージ資材へ、特定の顧客・環境・商材・運用が混ざっていないかの作業台帳。顧客の置き場は `docs/tickets/`（Git に載らない）。ここは本体側の洗い出しだけを書く。

見方: 名前、項目、選択リスト、画面部品、テストの文言が、その顧客の組織に無いと成り立たないものを混入とする。仕様にある更新商談、テナント条件、振込手数料は製品の言葉であり混入ではない。

## 外したもの

| 場所 | 中身 | 理由 |
| --- | --- | --- |
| `flexipages/FlexiPage3` | クイックアクション `Account.accounting_update` | パッケージに無い取引先アクション。商談ページの取引先欄から外した |
| 同 | 関連リスト `Opportunity_Onboardings__r` | パッケージに無いオンボーディング。サイドバーから外した |
| 同 | 表示名 `サンプルー商談` | 取得元のページ名。表示名は `商談` |
| 受注ウィザードと差し戻しの Jest | ラベル `成約パートナー①` | 顧客の商談項目名。見本は `表示項目` |

導入先のページ名、クイックアクション、関連リスト、商談項目のラベルは、このファイルへ戻さない。

## 見て混入ではなかったもの

- `force-app` のオブジェクト、`Loop_*`、同梱 CMDT（標準見積・標準請求・見本ウィザード項目、組織既定の会計設定）
- 契約履歴・契約サービス・見積商品・請求・請求明細・期間明細・科目マップ・組織設定・契約横断のレコードページ
- テストのメールと会社名（`example.com`、`株式会社テスト`、`テスト株式会社`）
- `a3fBW000000ZB5RYAW` は見本のレコード Id。顧客名ではない
- 表示行のために `EstimateWizardField__mdt.FieldApiName__c` を任意にした変更は、項目 API を空にできる製品機能。顧客の項目名は入っていない

## 残しているもの

## 見なかった範囲

`docs/Old` は凍結。`docs/tickets/` は顧客の置き場なので、混入の検査対象にしていない。
