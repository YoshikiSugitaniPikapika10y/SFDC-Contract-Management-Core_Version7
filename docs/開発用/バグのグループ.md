# 過去2か月のバグのグループ

作成日: 2026-10-25

パッケージ本体のバグを、操作者から見た失敗の出方で分けた記憶用の資料である。台帳は`要対応.md`と`対応済.md`のバグFIX。登録日は2026-08-28から2026-10-25で、2026-08-25より前は0件。過去2か月の全件は627件。未着手は`BUG-1478`の1件で、ほかは完了。

グループは重複せず、漏れない。1件だけのグループは作っていない。画面ごと、オブジェクトごとには分けていない。同じ失敗が呼び出し箇所の数だけチケットになっているものは、1グループにまとめた。

粒度の見本は次の2つである。ほかのグループも、この2つと同じくらいの失敗の幅にしてある。

1. 処理結果がエラーにもかかわらず、画面にエラーを表示せず無音になる
2. エラーメッセージは出るが、操作している場所から見えず、スクロールや画面上部へ行く

## 1. 処理結果がエラーにもかかわらず、画面にエラーを表示せず無音になる（9件）

保存や送付や発行は失敗している、または押しても反応が無い。画面には拒否の理由が出ない。ボタンが灰色になるだけ、例外を握りつぶす、入口の本体が無い、も含む。

- BUG-1336（2026-10-07、請求・入金） 小数と明細の残額超過で追加が灰色になるだけで、入出金フォームに理由が無い。理由をフォームに残す。空欄・0円・入出金日なしは理由を出さない
- BUG-1303（2026-10-05、見積） 見積書発行の「このファイルを送る」をキャンセルすると発行成功面に戻らない。送付の To はテキスト入力として出て、押しても文字が入らない
- BUG-1290（2026-10-05、見積） 見積を送るで送付するを押しても、キャンセルを押しても、画面が変わらず文も出ない。送付は応答まで待ち、失敗は理由を出し、成功は見積送付日時を書いて確認シェルを閉じる。キャンセルは送らずに閉じる
- BUG-1274（2026-10-04、見積） 見積書発行の成功後に「発行したファイルをプレビュー」または「このファイルを送る」を押しても何も起きない。発行中のポップアップの中で、プレビューは発行面の上に出し、送付は同じポップアップで開く。レコード画面は移さない
- BUG-169（2026-08-30、請求・入金） 請求ボード取得が請求書3択の設定エラーを握りつぶす
- BUG-212（2026-08-30、仕訳） 仕訳Lock／UnlockのAura入口が呼び出し本体を欠く
- BUG-325（2026-09-03、請求・入金） 既存請求明細の売上計上基準変更で、基準ロックの拒否文が出ない
- BUG-495（2026-09-05、見積） 見積書発行の発行するを押すとボタンだけ非活性になりPDFも成功画面も出ない
- BUG-1227（2026-09-14、見積） 見積書発行成功のプレビューと「このファイルを送る」が押しても反応しない

## 2. エラーメッセージは出るが、操作している場所から見えず、スクロールや画面上部へ行く（8件）

拒否や失敗の文は出ている。押したボタンの直下ではなく、ボードの最上部、スクロールしないと見えない位置、または読み直しの直後に消える。

- BUG-1399（2026-10-19、請求・入金） 請求の取消を押したときの拒否と、取消基準日プレビューの失敗が、請求ボード上部に出る
- BUG-1400（2026-10-19、請求・入金） 入出金の取消を開く前のプレビュー失敗が、請求ボード上部に出る
- BUG-1401（2026-10-19、請求・入金） 検収終了日を空にしたときと、変更プレビューの失敗が、請求ボード上部に出る
- BUG-1402（2026-10-19、請求・入金） 発行パネルで帳票を変えたあとのプレビュー失敗が、請求ボード上部に出る
- BUG-1405（2026-10-19、仕訳） 手動仕訳の登録と取消の成功と失敗が、押したボタンの直下に出ていない
- BUG-1309（2026-10-05、請求・入金） 入金登録で逆仕訳が要るとき、追加の1回目が取消の文で失敗し、逆仕訳基準日は失敗のあとで出る。追加の前に操作日入りで出し、空のエラーは欄を空にしたときだけにする
- BUG-1284（2026-10-05、土台） 版不一致で保存を拒んだ直後の読み直しが、拒否文を消す。後から保存した人には拒否も成功も出ない。先に保存した内容は残る
- BUG-1484（2026-10-25、請求・入金） 検収終了日の保存失敗が、押した検収終了日の直下に出ない

- BUG-984（2026-09-10、請求・入金） 請求ボードに縦スクローラが2本出て、枠側はホイールで動かない
