# ユーザ設定

作成日: 2026-09-04

本書の「ユーザ」は導入先クライアント（組織）である。Salesforce の User レコード単位の製品設定は持たない。

値の意味、画面の出し方、保存時の拒否は `仕様書_Core.md`、`仕様書_Accounting.md`、`共通基盤.md` のままである。本書が正とするのは作業順と、あとから変えたときの影響である。

導入ウィザードは持たない。入口は組織設定タブ、標準画面、Setup である（Core 第11.6節）。Hierarchy カスタム設定でも、製品は組織既定だけを読み書きする（Core 第11.6節）。シードはインストール直後だけ入る。人が消したあとのアップグレードでは戻さない。

No. が数字の行は、小さい番号を先にする。同じ番号の行どうしは順不同である。Accounting を使わない組織は No. 7〜10 を飛ばす。方針レコードは OFF のまま残し、最初の確定で OFF を固定する。
